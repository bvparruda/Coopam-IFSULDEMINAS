# Coopam-IFSULDEMINAS

> Web development project created for the Web Tech course, designed for future expansion as a Scientific Initiation Project (PIC) at IFSULDEMINAS - Campus Muzambinho.

## Problem

Coopam (Cooperativa-Escola dos Alunos do IFSULDEMINAS – Campus Muzambinho) is one of the favorite places for students (including myself) on campus.
There, we can buy amazing products, such as fresh yogurts and pastries.

However, students often don't know when specific products are available in stock, running the risk of making the trip only to find out their desired product is sold out.

## Solution

This project provides an intuitive website for Coopam. It features dedicated sections such as "Products", displaying real-time or updated stock availability to the school community.
